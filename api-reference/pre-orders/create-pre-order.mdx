---
title: "Create a pre-order"
description: "Creates a draft pre-order for one rented iMessage line, which has no effect until you confirm it."
openapi: "POST /v1/pre-orders"
---

- **Credential:** an API key.
- **Line-scoped keys:** the list of lines of a [line-scoped key](/authentication#line-scoped-keys) is not applied.
- **`Idempotency-Key`:** not honored. A repeated call creates another draft. See [Operations that honor the key](/idempotency#operations-that-honor-the-key).
- **Events:** none. See [Events](/guides/pre-orders#events).
- **Effect:** a draft creates no line and takes no payment. [`POST /v1/pre-orders/{id}/confirm`](/api-reference/pre-orders/confirm-pre-order) commits it: see [How a pre-order works](/guides/pre-orders#how-a-pre-order-works).
- **Caching:** the response carries `Cache-Control: no-store`, whatever its status.

## Errors

| Status | `error.code` | When |
| --- | --- | --- |
| 400 | `validation_failed` | An unknown field, `quantity` included, more than 5 area codes, a value of the wrong type, or a `metadata` over 20 keys or 8,192 bytes. |
| 400 | `android_rental_not_purchasable` | `billing_tier` is `rental_android`. |
| 400 | `tier_not_pre_orderable` | `billing_tier` is `byod_imessage`, `byod_android`, `shared_pool` or `shared_imessage`. |
| 400 | `billing_anchor_too_far` | `billing_anchor_at` is more than 31 days after the call. |

The errors that every operation shares are in [Errors](/errors-and-rate-limits#errors).
