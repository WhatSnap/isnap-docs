---
title: "Delete a webhook subscription"
description: "Deletes a webhook subscription, its signing secret and its delivery records."
openapi: "DELETE /v1/webhooks/{id}"
---

- **Credential:** an account API key. A trial key returns `401 unauthorized`.
- **Line-scoped keys:** the list of a [line-scoped key](/authentication#line-scoped-keys) is not
  applied here: the key deletes any subscription of the account.
- **`Idempotency-Key`:** not honored. A second call for the same id returns `404 not_found`.
- **Events:** none. No event announces the deletion.
- **Guide:** [Deleting a subscription](/webhooks/delivery#deleting-a-subscription). The deletion is
  permanent: the delivery records are deleted with the subscription, the requests not sent are
  dropped, and the events that only this subscription received leave the events feed. The operation
  returns `204` with no body.

## Errors

| Status | `error.code` | When |
| --- | --- | --- |
| 400 | `validation_failed` | `id` is not `wh_` followed by 25 letters or digits. |
| 404 | `not_found` | Your account has no subscription with this id, or it is already deleted. |

The errors that every operation shares are in [Errors](/errors-and-rate-limits#errors).
