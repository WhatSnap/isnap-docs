---
title: "Activate a reserved line"
description: "Turns a line you reserved into an active line."
openapi: "POST /v1/lines/{id}/activate"
---

- **Credential:** an API key. See [Activation](/guides/getting-a-line#activation).
- **Account:** wholesale partners only: any other account receives `402 checkout_required`. A direct account buys a line by writing to [support@isnap.ai](mailto:support@isnap.ai): see [Accounts](/concepts#accounts).
- **Line-scoped keys:** a [line-scoped key](/authentication#line-scoped-keys) gets `403 forbidden` unless the line is in its list.
- **Test keys:** an activation sent with an `isnap_test_` account key activates a real line, billed like any other: see [Test keys](/authentication#test-keys).
- **`Idempotency-Key`:** not honored. After a lost response, read [`GET /v1/lines/my`](/api-reference/lines/list-my-lines) before you call again: see [Retries](/guides/getting-a-line#retries).
- **Events:** none. See [Events](/guides/getting-a-line#events).

## Errors

| Status | `error.code` | When |
| --- | --- | --- |
| 400 | `validation_failed` | The body is invalid: for example, `billing_anchor_at` is not an ISO 8601 timestamp with a `Z` suffix. |
| 400 | `billing_anchor_too_far` | `billing_anchor_at` is more than 31 days after the activation. |
| 400 | `inbound_only_not_rental` | `inbound_only` is `true` and the line is not a rented line. |
| 400 | A code that starts with `line_` | The reserved line can no longer be acquired. The codes are those of [`reserve`](/api-reference/lines/reserve-line), with status `400` here. Release the line and choose another one. |
| 402 | `checkout_required` | Your account is not a wholesale partner. |
| 403 | `forbidden` | The request uses a line-scoped key, and the line is not in its list. |
| 409 | `line_not_reserved` | The line is not reserved by your account within the 15 minutes: the reservation expired or was released, the line was never reserved, or no line has this id. |
| 409 | `line_already_subscribed`, `subscription_cancel_failed` | The line carries a per-line subscription that could not be closed. |

The errors that every operation shares are in [Errors](/errors-and-rate-limits#errors).
