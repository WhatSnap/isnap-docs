---
title: "Convert a test line back to a rented line"
description: "Turns an active test line back into a rented line."
openapi: "POST /v1/lines/{id}/convert-from-test"
---

- **Credential:** an API key. See [Test lines](/guides/managing-lines#test-lines).
- **Account:** wholesale partners only: any other account receives `402 checkout_required`.
- **Line-scoped keys:** a [line-scoped key](/authentication#line-scoped-keys) gets `403 forbidden` unless the line is in its list.
- **`Idempotency-Key`:** not honored. A second call returns `409 not_a_test_line`.
- **Events:** none.

## Errors

| Status | `error.code` | When |
| --- | --- | --- |
| 402 | `checkout_required` | Your account is not a wholesale partner. |
| 403 | `forbidden` | The request uses a line-scoped key, and the line is not in its list. |
| 404 | `not_found` | No line has this id, or you do not own the line. |
| 409 | `not_a_test_line` | The line is not a test line. |
| 409 | `line_not_active` | The line is not `active`. |
| 409 | `test_line_in_use` | A trial that is not revoked uses the line. |
| 409 | `line_on_rented_macos_session`, `line_takes_no_macos_session` | The hosted macOS session of the line does not fit the change. Only iSnap can resolve it: write to [support@isnap.ai](mailto:support@isnap.ai) with the `trace_id` and `request_id` of the response. |

The errors that every operation shares are in [Errors](/errors-and-rate-limits#errors).
