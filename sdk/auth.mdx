---
title: "Authentication"
description: "Pass an API key to the client, switch environments, handle revocation."
---

The SDK reads an API key from the `apiKey` constructor option and adds
it as a Bearer token to every request:

```ts
import { ISnapClient } from '@isnap/sdk'

const isnap = new ISnapClient({
  apiKey: process.env.ISNAP_API_KEY!
})
```

## Where to get a key

Mint one in the dashboard at
[platform.isnap.ai](https://platform.isnap.ai) under
**Developers → API keys → Create key**. Pick `test` for a sandbox key
or `live` for production. Copy the full string immediately — the
dashboard shows the suffix once.

## Key formats

| Prefix | Environment |
|---|---|
| `isnap_live_*` | Production. Use against `api.isnap.ai`. |
| `isnap_test_*` | Sandbox. Real-shaped responses, never hits a real device. |

## Switching environments

The SDK has no `environment` enum — pass a different `baseUrl`:

```ts
const prod = new ISnapClient({
  apiKey: process.env.ISNAP_LIVE_KEY!
  // baseUrl defaults to https://api.isnap.ai
})

const sandbox = new ISnapClient({
  apiKey: process.env.ISNAP_TEST_KEY!,
  baseUrl: 'https://api.isnap.ai'
})
```

Run two `ISnapClient` instances if you need to talk to multiple
environments from the same process.

## Scoped keys

When you create a key, you can scope it to a specific list of lines.
A scoped key:

- Can send from and read those lines.
- Cannot see or act on lines outside the scope.
- Cannot acquire a new line through the assignment endpoint.

Scoped keys are useful for granting limited access — for example, a
specific service that should only ever send from one line.

## Rotation

Rotate by minting a new key and revoking the old one. Zero-downtime:

1. Mint the new key.
2. Roll it out across your services (env vars / secret manager).
3. Verify it's in use (audit log shows the new key).
4. Revoke the old key.

If you suspect a leak, **revoke first, mint after.** A short outage is
better than a leaked key in the wild.

## Errors the SDK throws

| Class | When |
|---|---|
| `AuthenticationError` (401) | Missing or revoked key, malformed string, or environment mismatch (e.g. live key on a sandbox baseUrl). |
| `PermissionDeniedError` (403) | Scoped key tried to act on a line outside its scope, or attempted a forbidden operation. |

Both are subclasses of `APIError`. See [SDK → Errors](/sdk/errors) for
the full hierarchy.
