# isnap-docs

Public documentation site for iSnap, deployed on [Mintlify Cloud](https://mintlify.com)
at [docs.isnap.ai](https://docs.isnap.ai).

## Local preview

```bash
bunx mintlify dev
```

Opens [http://localhost:3000](http://localhost:3000) with hot reload.

## Structure

- `mint.json` — site config (nav, theme, branding)
- `introduction.mdx`, `quickstart.mdx` — landing + 5-min onboarding
- `guides/` — partner integration guides (sending messages, webhooks, BYOD, trials)
- `concepts/` — long-form conceptual docs (BYOD vs rental, channels, quotas, deprecation lifecycle)
- `sdk/` — `@isnap/sdk` install + usage + examples
- `api-reference/` — auto-rendered from `openapi.json`
- `versioning.mdx` — version policy + `GET /v1/version`
- `changelog.mdx` — mirrors `iSnap-App/docs/api-contract.md` §8
- `scripts/filter-openapi.mjs` — strips internal-only routes from the upstream spec
- `images/` — logo + favicon + diagrams

## OpenAPI spec source

Today: vendored copy at `api-reference/openapi.json`, regenerated by
`scripts/filter-openapi.mjs` from `iSnap-App/packages/backend/openapi.json`.

Once `spec.isnap.ai/openapi.json` is live (WHA-704), `mint.json` will switch to
the remote URL and the local copy can be dropped.

## Deployment

Mintlify Cloud auto-deploys every push to `main`. Preview deploys on every PR.
DNS: `docs.isnap.ai` CNAME → Mintlify-provided hostname.
