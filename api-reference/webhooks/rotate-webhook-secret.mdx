---
title: "Rotate a signing secret"
description: "Replaces the signing secret of a webhook subscription and returns the new one once."
openapi: "POST /v1/webhooks/{id}/rotate-secret"
---

- **Credential:** an account API key. A trial key returns `401 unauthorized`.
- **Line-scoped keys:** the list of a [line-scoped key](/authentication#line-scoped-keys) is not
  applied here: the key rotates the secret of any subscription of the account.
- **`Idempotency-Key`:** not honored. A second call replaces the secret again. If you lose the
  response, rotate again.
- **Events:** none. No event announces the rotation.
- **Secret:** the response contains the signing secret: do not log it. No other operation returns it.
- **Guide:** [Secret rotation](/webhooks/delivery#secret-rotation). The rotation takes effect
  immediately: every request sent after it is signed with the new secret only.
  `old_secret_expires_at` is the time of the rotation plus 5 minutes, and it has no effect on what
  iSnap sends.

## Errors

| Status | `error.code` | When |
| --- | --- | --- |
| 400 | `validation_failed` | `id` is not `wh_` followed by 25 letters or digits. |
| 404 | `not_found` | Your account has no subscription with this id. |

The errors that every operation shares are in [Errors](/errors-and-rate-limits#errors).
