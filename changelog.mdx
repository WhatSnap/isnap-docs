Every change to the iSnap API contract lands here, with the date, the
new version, and what changed.

## 1.1.0 — 2026-05-05

§2.1 amendment.

- Added **`GET /v1/version`** — unauthenticated probe returning the
  current API version, so SDKs and your code can pre-flight a
  compatibility check at startup.
- Introduced the **deprecation lifecycle**: routes flagged for
  removal now emit `Deprecation`, `Sunset`, and
  `Link rel="successor-version"` headers (RFC 9745 / RFC 8594 /
  RFC 8288). Removed routes return **410 Gone** with `removed_at` and
  `successor` fields.
- The TypeScript SDK warns once per (method × path × sunset) when it
  encounters a `Deprecation` header, so deprecations surface in your
  logs ahead of removal.

## 1.0.0 — 2026-04-30

Initial v1 contract freeze. From this point forward:

- Breaking changes require a `/v2/*` namespace and a migration
  window.
- Additive changes (new fields, endpoints, webhook events) ship as
  `1.x` minor bumps and stay backward-compatible.
- Every contract change lands here with a dated entry.
