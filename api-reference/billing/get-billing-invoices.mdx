---
title: "List invoices"
description: "Past invoices on your account — amount due, paid, links to PDF and hosted view."
openapi: "GET /v1/billing/invoices"
---

Returns invoices on your account, most recent first. iSnap mirrors
Stripe's invoice records — each one corresponds to a billing period
(typically one calendar month).

## Response shape

```json
{
  "success": true,
  "data": [
    {
      "id": "in_...",
      "status": "paid",
      "amount_due": 25000,
      "amount_paid": 25000,
      "currency": "usd",
      "invoice_pdf": "https://...stripe.com/...pdf",
      "hosted_invoice_url": "https://invoice.stripe.com/i/..."
    }
  ],
  "trace_id": "tr_...",
  "request_id": "req_..."
}
```

| Field | Notes |
|---|---|
| `status` | `paid`, `open`, `void`, `uncollectible`, `draft`. |
| `amount_due` | Total in **cents** (e.g. `25000` = $250.00). |
| `amount_paid` | Cents paid so far. Equals `amount_due` for paid invoices. |
| `currency` | ISO 4217 lowercase (`usd`). |
| `invoice_pdf` | Direct PDF link. May expire — refresh by re-calling this endpoint. `null` until the invoice is finalized. |
| `hosted_invoice_url` | Stripe-hosted view (browsable, downloadable PDF). |

## What's on an invoice

Each line item maps to a billable iSnap subscription line (rental or
BYOD slot). The full calendar month is billed regardless of when the
line was activated mid-cycle — see
[wholesale billing rules](/api-reference/billing/post-billing-checkout#billing-model--locked-in-rules).

## Use cases

- **Finance reconciliation** — pull invoice IDs and amounts into your
  own ledger.
- **Customer-facing receipts** — expose `hosted_invoice_url` in your UI
  for download.
- **Audit on cancel** — confirm the final invoice after a cancel-at-
  period-end posts.

## Errors

Universal codes (`401 invalid_api_key`, `500`, `503`) and the envelope
shape are documented in
[Conventions → Errors](/api-reference/introduction#errors). This
endpoint has no endpoint-specific error codes.
